# Engineering Economics Calculator 📈

Aplicación web desarrollada para facilitar la resolución de problemas de Ingeniería Económica mediante diferentes calculadoras financieras. El sistema permite calcular operaciones relacionadas con interés simple, interés compuesto, anualidades y gradientes, proporcionando una herramienta práctica para estudiantes y profesionales.

## Características

- Calculadora de interés simple.
- Calculadora de interés compuesto.
- Calculadora de anualidades anticipadas y vencidas.
- Calculadora de gradientes crecientes y decrecientes.
- Cálculo de:
  - Valor Presente (VP)
  - Valor Futuro (VF)
  - Tasa de interés
  - Tiempo
  - Intereses
  - Cuotas
- Interfaz web intuitiva y fácil de utilizar.
- Compatible con dispositivos de escritorio y móviles.

## Funcionalidades

### Interés Simple

Permite calcular:

- Valor Presente (VP)
- Valor Futuro (VF)
- Interés generado
- Tiempo
- Tasa de interés

### Interés Compuesto

Incluye cálculos de:

- Valor Presente
- Valor Futuro
- Tiempo
- Tasa de interés
- Interés compuesto

### Anualidades

El sistema incorpora cálculos para:

- Anualidades Anticipadas.
- Anualidades Vencidas.
- Valor Presente.
- Valor Futuro.
- Tiempo.
- Cuotas.

### Gradientes

Permite resolver:

- Gradientes Lineales Crecientes.
- Gradientes Lineales Decrecientes.
- Gradientes Geométricos Crecientes.
- Gradientes Geométricos Decrecientes.

Incluyendo cálculos de:

- Valor Presente.
- Valor Futuro.
- Valor de la anualidad.
- Cuotas.

## Instalación

### Clonar el repositorio

```bash
git clone https://github.com/USUARIO/engineering-economics-calculator.git
```

### Ejecutar el proyecto

Abrir el archivo:

```text

```

También puede ejecutarse mediante un servidor local como **Live Server** en Visual Studio Code.

## Organización del proyecto

La aplicación está organizada por módulos según el tipo de cálculo financiero:

| Módulo | Descripción |
|--------|-------------|
| IS | Interés Simple |
| IC | Interés Compuesto |
| AA | Anualidades Anticipadas |
| AV | Anualidades Vencidas |
| GLC | Gradientes Lineales Crecientes |
| GLD | Gradientes Lineales Decrecientes |
| GGC | Gradientes Geométricos Crecientes |
| GGD | Gradientes Geométricos Decrecientes |

Esta estructura facilita el mantenimiento del código y la incorporación de nuevas funcionalidades.
